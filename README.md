# Scentinel AI – Digital Nose

## Project Overview
Scentinel AI is a Physical AI-based safety device designed to assist people with anosmia by detecting hazardous and spoiled odors that they cannot smell.

## Problem
People with anosmia may not detect gas leaks, smoke, or spoiled food. Scentinel provides an accessible warning through voice and visual alerts.

## Key Features
- Gas and smoke detection
- Odor and VOC monitoring
- Temperature and humidity monitoring
- Automatic hazard classification
- Voice-based safety alerts
- Arduino-based physical prototype

## Technologies
- ESP32
- MQ-2 Gas Sensor
- MQ-135 Gas Sensor
- BME680
- DHT22
- Weka Machine Learning
- SVM classification

## Dataset
The project uses an odor classification dataset for machine-learning experimentation and Weka-based classification.

## Current Status
- Dataset analysis completed
- Weka classification completed
- Python simulation completed
- Hardware prototype under development
  

## Future Development
The system will integrate the sensors,classification system and voice-alert module into a working physical prototype.
